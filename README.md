## 📖 Project Overview

This project builds a **restaurant recommendation system** using real Swiggy restaurant data from across Indian cities. Users can set their preferences through an interactive web app and receive personalised restaurant recommendations instantly.

**Core capabilities:**
- Data cleaning and preprocessing on messy, real-world Swiggy CSV data
- One-Hot Encoding of categorical features (city, cuisine)
- Min-Max Scaling of numerical features (rating, cost, rating count)
- Two recommendation methods: **Cosine Similarity** and **K-Means Clustering**
- Interactive Streamlit UI with restaurant cards, metrics, and CSV download

## ⚙️ How It Works

### 1. Data Preprocessing (`data_preprocessing.py`)

- **Duplicate removal:** Fully duplicate rows are dropped.
- **Column parsing:**
  - `rating` — invalid values like `"--"` and `"Too Few Ratings"` → `NaN`; valid range: 1.0–5.0
  - `rating_count` — strings like `"50+ ratings"` → `50.0` via regex
  - `cost` — `"₹ 1,500"` → `1500.0` by stripping `₹`, commas, and whitespace
- **Missing values:** Rows missing `name`, `city`, `cuisine`, `rating`, or `cost` are dropped. `rating_count` nulls are imputed with the column median.
- **Feature engineering:** `cuisine_primary` — the first token of the comma-separated cuisine field — reduces OHE cardinality.
- **Encoding:** `city` and `cuisine_primary` are One-Hot Encoded using `sklearn.OneHotEncoder`. The fitted encoder is saved as `encoder.pkl`.
- **Scaling:** `rating`, `rating_count`, and `cost` are Min-Max scaled to `[0, 1]`.
- **Index alignment:** `cleaned_data.csv` and `encoded_data.csv` share the exact same integer index so results can be correctly mapped back.

### 2. Recommendation Engine (`recommendation.py`)

**Query vector construction:**
1. User inputs (`city`, `cuisine`, `rating`, `cost`, `rating_count`) are normalised using the same min-max bounds from the cleaned dataset.
2. `city` and `cuisine_primary` are passed through `encoder.pkl` to produce an OHE vector.
3. Both parts are concatenated into a single `(1, n_features)` query vector.

**Cosine Similarity (method: `"cosine"`):**
```
similarity(A, B) = (A · B) / (‖A‖ × ‖B‖)
```
The query vector is compared against all rows of `encoded_data.csv`. The top-N indices by descending similarity score are mapped back to `cleaned_data.csv` for human-readable output.

**K-Means Clustering (method: `"kmeans"`):**
- A `KMeans` model (30 clusters, `random_state=42`) is trained on `encoded_data.csv` once and cached as `kmeans_model.pkl`.
- At query time, the query vector is assigned to its nearest cluster.
- Cosine similarity is computed only within that cluster → faster search on large data.
- Falls back to global cosine similarity if the assigned cluster is empty.

### 3. Streamlit App (`app.py`)

- **Auto-preprocessing:** On first launch, if artefacts are missing the app runs `data_preprocessing.main()` automatically.
- **Sidebar filters:** City, cuisine, rating, cost, rating count, method, and number of results.
- **Output cards:** Name, city, cuisine, address, rating, cost, match %, and Swiggy link.
- **Summary metrics:** Average rating, average cost, and average match score for the result set.
- **CSV download:** Export recommendations to a CSV file.
- **Dataset overview:** Displayed on the welcome screen (total restaurants, cities, cuisines, average rating, sample rows).

## 🚀 Installation & Setup

### Prerequisites
- Python 3.10 or higher
- Git

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/swiggy-restaurant-recommendation-system.git
cd swiggy-restaurant-recommendation-system

# 2. (Optional) Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run preprocessing to generate cleaned_data.csv, encoded_data.csv, encoder.pkl
python data_preprocessing.py

# 5. Launch the Streamlit app
streamlit run app.py
```

The app will open automatically at `http://localhost:8501`.

> **Shortcut:** You can also run `python setup_and_run.py` which handles cleanup and preprocessing in one step before you launch the app.

## 🖥️ Usage

1. Open the app in your browser at `http://localhost:8501`
2. Use the **sidebar** to set your preferences:
   - Select a **city** and **cuisine**
   - Adjust the **rating**, **cost**, and **rating count** sliders
   - Choose a **recommendation method** (Cosine Similarity or K-Means)
   - Set how many results to show
3. Click **🚀 Find Restaurants**
4. Browse the restaurant cards, or expand the full results table
5. Download recommendations as a CSV using the download button

## 💡 Key Insights

- A significant portion of Swiggy entries have `"--"` or `"Too Few Ratings"` for their rating field, indicating newly listed or low-traffic restaurants. These were excluded to maintain recommendation quality.
- Using `cuisine_primary` (only the first cuisine token) instead of the full comma-separated string greatly reduces OHE dimensionality while preserving the most important signal.
- Cosine similarity is particularly effective here because OHE vectors are sparse and high-dimensional — angular distance is more meaningful than Euclidean distance in such spaces.
- K-Means with 30 clusters provides a meaningful neighbourhood structure that makes per-cluster similarity search significantly faster on large datasets compared to a global search.
